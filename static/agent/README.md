# Boozang Agent Documentation

Public documentation for AI agents helping Boozang users.

## Purpose

This directory provides AI-readable documentation that enables:
- Customer AI assistants to learn Boozang
- Automated onboarding for new users
- Consistent guidance across AI platforms

