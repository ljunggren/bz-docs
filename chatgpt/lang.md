# 🌐 Most Common Full-Stack Setups (2025)

This document provides an overview of the most commonly used full-stack combinations in web development, including both open-source and Microsoft-based stacks.

---

## 🔝 Top Full-Stack Setups

| **Stack Name**     | **Frontend**                        | **Backend**              | **Database**               | **Runtime/Platform**     | **Use Case**                              |
|--------------------|-------------------------------------|---------------------------|-----------------------------|---------------------------|--------------------------------------------|
| **MERN**           | React.js                            | Express.js (Node.js)      | MongoDB                     | Node.js                  | Modern SPAs, JavaScript-only stack         |
| **MEAN**           | Angular                             | Express.js (Node.js)      | MongoDB                     | Node.js                  | Enterprise Angular apps                    |
| **LAMP**           | PHP / HTML / CSS                    | PHP (Apache)              | MySQL                       | Linux / Apache           | CMS sites, legacy systems                  |
| **LEMP**           | PHP / HTML / CSS                    | PHP (Nginx)               | MySQL                       | Linux / Nginx            | High-performance PHP apps                  |
| **JAMstack**       | React / Vue / SSGs (Next.js, etc.)  | APIs (headless/custom)    | Headless CMS / None / Any   | Vercel / Netlify         | Static or content-heavy sites              |
| **Django + React** | React.js or Vue.js                  | Django (Python)           | PostgreSQL / SQLite         | Python                   | Secure, data-driven web apps               |
| **Rails + React**  | React or Hotwire                    | Ruby on Rails             | PostgreSQL                  | Ruby                     | Rapid MVP development                      |
| **.NET (Microsoft)**| Blazor / Razor Pages / React       | ASP.NET Core (C#)         | SQL Server / PostgreSQL     | .NET Core / Azure        | Enterprise, fintech, secure backend apps   |

## 📘 Notes

- **React** continues to dominate frontend development.
- **.NET Core** and **Azure** are gaining popularity in enterprise and cloud-native development.
- **JAMstack** is favored for performance and scalability in static and headless setups.
